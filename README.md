# You Sneakcare

Website jasa cuci sepatu You Sneakcare, dibuat dengan Vite, React, dan Tailwind CSS. Order dikirim lewat WhatsApp.

## Menjalankan

```bash
npm install
npm run dev
npm run build
```

## Mengubah konten

- Harga dan layanan: `src/data/services.js`
- Nomor WhatsApp dan format pesan order: `src/lib/order.js`
- Testimoni: `src/components/Testimonials.jsx`
